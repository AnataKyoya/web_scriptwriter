Cara kerja
Tulis saja; format menyusul otomatis.
  • Judul adegan: baris diawali INT. EXT. EST. atau I/E (atau pilih lewat tombol Format baris).
  • Karakter: baris HURUF KAPITAL tanpa tanda akhir kalimat (atau pilih lewat tombol Format baris). Baris sesudahnya otomatis jadi dialog; baris (dalam kurung) jadi parenthetical.
  • Aksi: semua baris lain (atau pilih lewat Format baris). Tekan Enter sesudah dialog untuk kembali ke aksi.
  • Transisi: CUT TO: FADE OUT. atau diawali >.
  • (CONT'D): muncul di isyarat karakter bila karakter yang sama bicara lagi dalam adegan yang sama, hanya diselingi aksi (sampai batas "maks. aksi"), tanpa karakter lain di antaranya. Ia hanya tampilan, tidak tersimpan di teks, jadi hilang sendiri kalau urutan berubah. Menulis (CONT'D) manual tetap dihargai.
  • Format manual: pilih jenis baris lewat tombol Format baris di panel kanan (atau Alt+1 s/d Alt+6: adegan, aksi, karakter, dialog, parenthetical, transisi; Alt+0 deteksi ulang). Teks diformat otomatis: adegan jadi KAPITAL berawalan INT., karakter KAPITAL tanpa tanda baca akhir, parenthetical diberi kurung, dialog dibuat huruf biasa. Bisa untuk beberapa baris sekaligus. Jenis baris disimpan sebagai penanda terpisah, jadi tidak ada simbol tambahan di teks; simbol Fountain baru ditambahkan di file ekspor, itu pun hanya bila perlu.
  • Proyek: panel Proyek di kiri mengelompokkan script per proyek (tiap proyek punya id sendiri). Undang di proyek memberi kolaborator akses ke semua script di proyek itu, termasuk script yang ditambahkan kemudian. + Proyek membuat proyek beserta script pertamanya, + Script menambah script ke proyek itu, dan dropdown Naskah ini ada di proyek memindahkan script yang sedang dibuka.
  • Naskah baru: tombol + Naskah baru membuka naskah kosong dengan tautan sendiri. Naskah lama tidak terhapus; buka lagi dari daftar di jendela yang sama, atau lewat tautannya.
  • Hapus script: klik ikon tempat sampah di samping nama script (daftar Proyek) atau tombol Hapus di panel kanan. Penghapusan permanen dan hanya bisa dilakukan pemilik script.
  • Akun & database: klik Masuk (tautan lewat email) agar naskah tersimpan di akun dan muncul di semua perangkat. Pemilik bisa memakai Undang untuk memberi akses ke email lain. Tanpa masuk, naskah tetap tersimpan di browser ini.
  • Urungkan / Ulangi: Ctrl+Z, Ctrl+Y (atau Ctrl+Shift+Z; Cmd di Mac), atau tombol di atas naskah. Riwayat maksimal 30 langkah dan hanya mencakup perubahanmu sendiri, jadi tulisan kolaborator tidak ikut terhapus.
  • Saran otomatis: saat menulis judul adegan (awalan INT./EXT., lokasi dari adegan sebelumnya, lalu waktu seperti MALAM) dan nama karakter (termasuk (V.O.), (O.S.)), muncul daftar saran. Tekan Tab untuk memilih, ↑↓ untuk menggeser, Enter setelah menggeser, Esc untuk menutup. Di layar sentuh, ketuk salah satu saran.
  • Impor: klik Impor .txt atau seret file ke halaman. Nomor adegan dipertahankan, indentasi karakter/dialog/transisi dibaca, lalu semuanya dirender ulang dengan format di sini.
  • Kolaborasi: masuk dengan akun, klik Undang untuk memberi akses lewat email, lalu bagikan tautan naskah. Perubahan sampai ke semua orang secara langsung. Tanpa akun, kolaborasi live butuh server signaling WebRTC sendiri (lihat README).
